## 📌 개요

단지내 토목 우수·오수 배관 산정을 위한 웹 애플리케이션입니다.

- **우수 배관**: 합리식(Rational Method) 기반 — KDS 61 10 00
- **오수 배관**: 오수 유량 산정 — 하수도설계기준
- **Manning 공식** 적용 유속·유량 검토
- 반응형 UI (데스크탑 · 태블릿 · 모바일)
- **PWA** — 오프라인 지원, 홈화면 설치 가능
